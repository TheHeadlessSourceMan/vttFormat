# vttFormat
WEBVTT
Video Text Track

Basically all captions, be it closed caption
or transcripts of meetings.

NOTE: at this time, the format support is minimal.
It is foruced mostly on reading meeting transcripts.

See:
https://w3c.github.io/webvtt/
